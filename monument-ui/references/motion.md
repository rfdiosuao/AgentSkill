# 动效：主角之外，让小东西有手感

Monument 的大画面靠构图和光立住，但用户真正用手碰的是前景层里的小东西：开关、按钮、加载、数字。这一层的动效决定"做工好不好"。

原则一句话：**动效是对用户动作的回答，不是装饰。** 没人碰它，它就安静。

## 1. 三类动效，各算各的预算

| 类型 | 数量 | 时长 | 何时出现 |
|---|---|---|---|
| 入场 | 每页 1 次 | ≤1200ms | 页面加载，只给主体和标题 |
| 常驻 | ≤1 个 | 循环 4–12s | 呼吸 / 漂浮 / 光移三选一，只给主体 |
| 反馈 | 每个交互元素都要有 | 见下表 | 用户 hover、按下、切换时 |

反馈不占常驻名额，但同屏同时运动仍然 ≤3 个元素。

## 2. 反馈的时长与缓动

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover 亮起 / 位移 | 120–180ms | `cubic-bezier(.2,.8,.2,1)` |
| 按下（scale .96–.98） | 80–120ms | `ease-out` |
| 松开回弹 | 200–280ms | 轻微过冲 `cubic-bezier(.34,1.56,.64,1)`，只给 ≤64px 的小物件 |
| 开关 / 状态切换 | 280–450ms | 弹簧，或 `cubic-bezier(.16,1,.3,1)` |
| 面板展开 | 300–500ms | `cubic-bezier(.16,1,.3,1)` |
| 退出 / 收起 | 进入时长的 60–70% | `ease-in` |

规则：
- 大物件不回弹。过冲只给按钮、开关滑块这种小东西，主体一弹就廉价。
- 退出永远比进入快，用户已经不在乎它了。
- 数字变化用 `font-variant-numeric: tabular-nums`，逐位滚动，不要整体淡入淡出。

## 3. 状态用材质和光表达

普通做法：开关打开，底色从灰变成绿。
Monument 做法：开关打开，**里面的材质发生了一件事**。

六种可以直接用的表达：

| 表达 | 关 → 开发生了什么 | 适合 |
|---|---|---|
| 点灯 | 暗面上的一道缝或一圈边亮起，暖光只在开启后出现 | 电源、启用、深色模式 |
| 液体 | 一团黑色液体被吸到另一端，激活时表面起刺或拉丝 | 强调"有力量"的开关 |
| 玻璃 | 玻璃块平移，底下的光从冷色切到暖色，边缘高光跟着移动 | 日 / 夜、主题切换 |
| 场景 | 胶囊里装着一个小场景，切换时场景从白天变成夜晚 | 主题切换、有品牌个性的设置 |
| 天体 | 球体的受光面旋转，像月相变化 | 进度、时间、亮度 |
| 粒子流 | 一条通道里的颗粒流量随数值变粗或变细 | 漏斗、转化率、流量 |

通用约束：
- **强调色只在激活态出现。** 关闭态必须是中性色，打开那一刻光才出现，这样光才有意义。
- 一个页面只选一种表达，所有开关用同一种。混用就成了样品陈列。
- 光源方向和页面的 key 灯一致，见 `material-light.md`。
- 做不出真材质时，用 CSS 渐变和阴影的位移去模拟，并老实说明是模拟的。

## 4. 加载与等待

- 单色，最多 3 个元素，循环周期 0.8–1.6s。
- 形状尽量和产品有关系：录音产品用波形，时间产品用钟，AI 产品可以用"思考中"的文字闪烁。通用转圈是最后选择。
- 超过 2 秒的等待要给进度或阶段文字，不能只转圈。
- 加载动画也算"同时运动"的元素，计入 ≤3 的上限。

## 5. 降级

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
  }
}
```

降级后：
- 保留状态变化本身（开关还是要能看出开了），去掉位移、缩放、循环和视差。
- 常驻动效直接停在一个好看的静帧上，不是停在第 0 帧。
- 无 WebGL 时，主体换成一张静态渲染图或 CSS 版本，页面结构不变。

## 6. 动效里的廉价信号

1. 每个元素都 fade-up 入场
2. 发光常驻 `pulse`，强调色一直在闪
3. 滚动视差用在所有图层上，而不是只给远景
4. 大面积元素弹跳过冲
5. hover 时元素变大超过 1.05 倍
6. 动画时长全部一样，没有快慢之分

## 7. 验收

- 列出页面上所有会动的东西，标明属于哪一类（入场 / 常驻 / 反馈）
- 每个交互元素写出 hover / press / focus 的时长
- 打开 reduced-motion 后截一张图（或说明降级后的静帧是哪一帧）
