# 验收表：19 条，逐条给证据

不给证据等于没做。每条后面写实际数字或截图。

## 0. 终局测试（不过，其余全部无效）

0. **裸版测试**：`?bare=1` 去掉所有装饰后，主体 + 主标题 + 一个按钮依然成立。
   证据：正常版与裸版两张截图。

## A. 结构（任一不过，回构图重排）

1. 主角是一个名词，一句话说得清是什么
2. 画面里没有第二个抢戏的主体
3. 主角占画面 40–65%
4. 留白 ≥30%，且是有质感的留白（黑场 / 雾 / 天光 / 水面）
5. 纵深三层齐全，亮度曲线单调
6. 构图不对称，主体中线偏移 ≥8%

## B. 层级与信息

7. 可见 UI 元素 ≤30（真的数一遍）
8. 主按钮 1 个，次按钮 ≤1 个
9. 字号只有两档：巨大标题 + 11–13px
10. 一屏正文 ≤2 段
11. 存在极小参照物，尺度比 ≥40:1

## C. 材质与光

12. 一个材质做到有使用痕迹，其余降级
13. 三盏灯方向一致（各一句话说明方位）
14. 全屏发光覆盖 ≤15%
15. 后期只有三件事（暗角 / 颗粒 / 极轻色差）

## D. 记忆点与可用性

16. 异常点恰好 1 个，且不在视觉重心上
17. 色族 ≤3（主色 + 强调色 + 中性）
18. 交互元素有 hover / focus 反馈；减动效与无 WebGL 有降级

## 输出格式

```
裸版测试 通过（附两张截图）
结构 6/6 · 层级 5/5 · 材质 4/4 · 记忆点 3/3
元素数 23 · 主按钮 1 · 色族 2 · 主角占比 52% · 留白 34% · 比例 46:1
不过的项：-
```

## 如果不过

**先改构图，不许加装饰。**

顺序：换锚点 > 重排重量 > 调光位 > 换材质 > 最后才动细节。

加一层发光、加一个粒子、加一张卡片，都不在补救清单里。它们只会让"没构图"变成"闪亮的没构图"。
