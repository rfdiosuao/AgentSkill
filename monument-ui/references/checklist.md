# 验收表：19 条，逐条给证据

不给证据等于没做。每条后面写实际数字或截图。

## 0. 终局测试（不过，其余全部无效）

0. **裸版测试**：`?bare=1` 去掉所有装饰后，主体 + 主标题 + 一个按钮依然成立。
   证据：正常版与裸版两张截图。截不了图时，给裸版开关代码 + 裸版剩余元素清单，并标注"未截图验证"。

## A. 结构（任一不过，回构图重排）

1. 主角是一个名词；截图缩到 200px 宽仍认得出；5 秒内看得出产品是卖什么的
2. 画面里没有第二个抢戏的主体；定调（重档 / 轻档）与产品类型相符
3. 主角占画面：重档 40–65%，轻档 25–45%
4. 留白 ≥30%，且是有质感的留白（黑场 / 雾 / 天光 / 水面）
5. 纵深三层齐全，亮度曲线单调
6. 构图不对称，主体中线偏移 ≥8%；390px 宽时主体完整，发光不压正文

## B. 层级与信息

7. 可见 UI 元素 ≤30（真的数一遍）
8. 主按钮 1 个，次按钮 ≤1 个
9. 字号最多三档：巨大标题 + 11–13px 标签，有正文时再加 15–17px；段落不用 11–13px
10. 一屏正文 ≤2 段
11. 机制 A：存在看得见的极小参照物，尺度比 ≥40:1；其他机制可填"不适用"

## C. 材质与光

12. 一个材质做到有使用痕迹，其余降级
13. 三盏灯方向一致（各一句话说明方位）
14. 全屏发光覆盖 ≤15%
15. 后期只有三件事（暗角 / 颗粒 / 极轻色差）

## D. 记忆点与可用性

16. 异常点恰好 1 个，且不在视觉重心上
17. 色族 ≤3（主色 + 强调色 + 中性）
18. 交互元素有 hover / press / focus 反馈，时长在 `motion.md` 的范围内；可点击区域 ≥44px；`prefers-reduced-motion` 与无 WebGL 时有降级

## 如果不过

**先改构图，不许加装饰。**

顺序：换锚点 > 重排重量 > 调光位 > 换材质 > 最后才动细节。

加一层发光、加一个粒子、加一张卡片，都不在补救清单里。它们只会让"没构图"变成"闪亮的没构图"。
