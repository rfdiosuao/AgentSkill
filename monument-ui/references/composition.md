# 构图：重量、纵深、不对称

先画这个，再写代码。代码写不出秩序，构图才有秩序。

## 1. 重量分配

把画面分成 3×3，标出每格的视觉重量，目标：

- 主角占 40–65% 面积，落在 4 / 5 / 7 / 8 格之一，**不要正中格**。
- 标题占 15–25% 重量，压在主体对角线的另一侧。
- 留白 ≥30%，且集中在重量的反方向，给重量一个出口。
- 任何单个元素的重量不超过 65%，超过就是"堵"。

## 2. 三层纵深（缺一层就平）

| 层 | 位置 | 亮度 | 对比度 | 手法 |
|---|---|---|---|---|
| 前景 UI | 最前 | 中间调 | 中 | 标题、按钮；0–2px 模糊与主体分离 |
| 中景主体 | 画面中 | 画面极值（最亮或最暗） | 高 | 最锐、最实、材质最讲究 |
| 远景环境 | 最后 | 压暗 20–40% | 低 | 雾、暗角、颗粒，越远越暗越虚 |

三层同亮度 = 贴纸拼图，不是空间。

## 3. 五种合法的不对称排列

1. 主体左下 / 标题右上
2. 主体占右下 2/3 / 大字压左上并出血
3. 整体极简居中，但加一条偏离中心的光带或细线破对称
4. 主体超大出血，只露局部——"看不全"本身就是记忆点
5. 大面积留白 + 极小主体（高风险，需要材质极强才立得住）

禁止：正中对称 + 居中标题 + 居中按钮，三件套一起出现。

## 4. 尺度阶梯

相邻层级字号差至少 3 倍，否则层级读不出来。

推荐两档制：`clamp(4rem, 9vw, 12rem)` + `11–13px`。中间档尽量不留。

## 5. 留白不是空

留白必须是四种之一：

- **黑场**：≤ `#0A0A0C`，但不能死黑，要有 1–2 个极暗噪点层次
- **雾**：有浓度梯度，近处淡远处浓（或反之，但要一致）
- **天光**：有方向，能看出太阳在哪一侧
- **水面**：有反射，反射要比本体虚一档

纯 `#fff` 空白是最低级的留白。

留白里必须有极少量信息：一颗星、一粒尘、一行 11px 的字。零信息的留白 = 没做完。

## 6. 网格可以破，但必须知道在哪破

用 12 列栅格对齐所有文字锚点，主体允许跨列出血。**文字永远对齐栅格，主体永远不完全对齐**——秩序与意外同时存在，才是"极简秩序 × 超现实主体"。
