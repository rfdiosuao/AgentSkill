# 反例库：什么让画面一眼廉价

## 一眼廉价的 6 个信号

1. 紫 / 蓝渐变背景 + 白色卡片
2. 6 个以上卡片等宽排列
3. 全屏发光，bloom 覆盖大面积
4. 玻璃拟态 + 模糊 + 描边的万能组合
5. 居中对称 + 居中标题 + 居中按钮
6. 3 种以上字体 / 4 种以上主色

## 判据（能算出来，不靠感觉）

| 判据 | 阈值 | 含义 |
|---|---|---|
| 可见元素数 | >30 | 挤 |
| 色相族 | >3 | 花 |
| 互不相关的渐变 | >2 处 | 堆料 |
| 同时运动的元素 | >3 | 噪音 |
| 主角面积 | <40% | 没主角 |
| 留白 | <30% | 没有呼吸 |
| 字号档位 | >3 | 层级糊 |
| 灯数 | >3 | 没有光位概念 |

判据能算，就不用吵"我觉得"。数出来，谁都能看。

## 被要求"加东西"时的标准回复

- **"再炸一点"** → 不加元素。加大主体、压暗环境、换更硬的材质、扩留白。
- **"多放几个卖点"** → 先问唯一主角是谁；其余改一行等宽小字，或一个切换按钮。
- **"参考 X 产品"** → 只提取秩序（网格 / 层级 / 光），不搬外观和配色。
- **"太空了"** → 在留白里加极少量信息（星、尘、一行字），不是加卡片。
- **"按钮不够多"** → 1 主 + 文字链；真要并列操作的，收进一个"更多"。

## 什么时候这套不适用

数据密集界面：看板、表格、设置页、批量操作台。

这时**保留**：一个主角（最重要的数字或那张图）、三层纵深、唯一记忆点。
这时**放弃**：≤30 元素、30% 留白。

放弃时必须写出来，例如："这个看板需要 48 个可见元素和 18% 留白，我保留单主角和三层纵深，放弃元素上限。"

## 一个反直觉的判断

**复杂不等于高级，克制也不等于高级。** 高级感的本质是"每一个决定都有理由"。

所以这套规则里所有的数字都不是审美偏好，而是可被质疑、可被改的具体约定。用户要打破某条，你就说清打破它的代价——而不是拒绝执行。
