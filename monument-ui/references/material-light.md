# 材质与光：高级感的两个真正来源

## 三盏灯（数值可直接落进代码）

- **key**：方位 120° 上侧；强度 1.0；色温 5200–6500K；负责画面唯一的强高光。
- **rim**：主体背后 ±160°；强度 0.55–0.65；色温 6500–9000K（偏冷）；只勾轮廓，宽度 ≤ 主体轮廓的 8%。
- **ambient**：≤0.15；色温跟随环境；只负责让暗部不透死，不负责照亮。

禁止：4 盏以上灯、全屏 bloom 覆盖 >15%、无方向的均匀环境光。整个页面到处发光，是廉价感的头号来源。

## 材质配方

| 材质 | roughness | metalness | 必须加的细节 |
|---|---|---|---|
| 黑曜石 | 0.05–0.12 | 0.15 | 边缘崩口、内部一点点透光 |
| 拉丝金属 | 0.25–0.35 | 0.9 | 单向划痕、指纹污渍 |
| 青铜/氧化 | 0.45–0.60 | 0.8 | 绿锈、磨损发亮区 |
| 玻璃 | 0.02–0.06 | 0 | 厚薄不均、边缘折射、内部气泡 |
| 玉石 | 0.30 | 0 | 半透、内部絮状纹理 |
| 石头 | 0.70–0.90 | 0 | 颗粒、裂缝、积尘 |
| 丝绸 | 0.60 | 0 | 各向异性高光、褶皱 |
| 水 / 雾 | — | — | 必须有浓度梯度，不能均匀 |

**规则**：一个画面里只允许一个材质做到"能看见被使用过"，其余全部降到 70%。全都精致 = 全都不精致。

## 伪 3D 也要守物理

用 CSS / SVG / 2D canvas 做的时候：

1. 光源只能有一个方向
2. 所有阴影朝向必须一致
3. 模糊量随"距离"单调变化（越远越糊）
4. 高光只出现在迎光面，不该两侧都亮

做不到就老实说这是平面风格。伪 3D 装不好，比承认是平面更廉价。

## 后期只做三件事

1. **暗角**：把边缘压暗 10–20%，视线自然回到主体
2. **极细颗粒**：`opacity: 0.02–0.04`，消除数字感的死板
3. **一层极轻色差或柔焦**：≤1px，注意是"一层"

禁止：多层 bloom + 色散 + 故障 + 描边 全上。四个一起上，画面立刻变成 2019 年的作品集模板。

## 光影检查的三个问题

1. 这张图的光，能用一句话说出从哪来吗？
2. 闭眼再睁开，视线先落在主体上吗？
3. 把画面缩到 200px 宽，主体还认得出来吗？

三个都是"是"，光就成了。
