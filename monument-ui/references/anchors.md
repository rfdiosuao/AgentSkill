# 锚点库：18 个"让人停顿"的主体

选锚点看的是**停顿机制**，不是"哪张好看"。四种机制决定观众为什么停下来，换风格不换机制 = 同一张图换皮。

## 四种停顿机制

| 机制 | 观众脑子里的问题 | 靠什么制造 |
|---|---|---|
| **A 尺度压迫** | 这东西得有多大？ | 巨大主体 + 极小参照物 |
| **B 物理不可能** | 它为什么浮着 / 立着？ | 违反重力、透视、材质常理 |
| **C 不该被发现** | 我是不是不该看这个？ | 黑暗环境 + 一束探查光 |
| **D 介质错位** | 这是实物还是画？ | 材料与语境不匹配（墨在现实里、白色无边界） |

同一个页面里只允许一种机制。混两种，注意力就散了。

## 怎么用

1. **按机制选，不按风格选。** 用户要"科技感"，A 和 B 都能做到；先定机制再定样子。
2. **改写，不照抄。** 必须替换至少一个变量：材质 / 光温 / 异常类型 / 尺度方向（巨大 ↔ 极小）。并在输出里写明换了哪个。原样复述 = 换皮。
3. **同批多张要拉开差异。** 三张一起出时选"机制不同"的三个，别选"颜色不同"的三个。推荐最小差异集：`01 巨石（A）` + `02 赛博核心（B）` + `14 水墨（D）`。
4. **锚点不是越多越好。** 一个项目只用一个锚点贯穿全站；换锚点等于换品牌。

## 自造的三个条件

- 能用一个名词说清（说不清就不是锚点）
- 有明确的"停顿机制"，且只有一种
- 旁边能放下一个极小参照物

三个不满足，就回到这 18 个里挑一个。
