# 锚点库：18 个场景锚点 + 6 个产品锚点

选锚点看的是**停顿机制**，不是"哪张好看"。四种机制决定观众为什么停下来，换风格不换机制 = 同一张图换皮。

先看 SKILL.md 第 0 步定调：**重档**用 18 个场景锚点，**轻档**用文末的 6 个产品锚点。

## 实现模式能选哪些

场景锚点里的岩石、云海、体积光、水面，需要真实渲染图或 3D 才立得住。只写代码、手里没有渲染图时，用 CSS / SVG 去模拟这些材质，结果一定廉价。

- **只有代码时可选**：02 赛博核心、06 行星边缘、13 红月、17 纯白虚空、18 白点，以及全部 6 个产品锚点。它们靠几何、渐变和单一光源就能成立。
- **其余场景锚点**：只用于出图模式，或者用户提供了渲染图 / 3D 资源时。没有资源却选了它们，等于先把材质分丢掉。

## 四种停顿机制

| 机制 | 观众脑子里的问题 | 靠什么制造 |
|---|---|---|
| **A 尺度压迫** | 这东西得有多大？ | 巨大主体 + 极小参照物 |
| **B 物理不可能** | 它为什么浮着 / 立着？ | 违反重力、透视、材质常理 |
| **C 不该被发现** | 我是不是不该看这个？ | 黑暗环境 + 一束探查光 |
| **D 介质错位** | 这是实物还是画？ | 材料与语境不匹配（墨在现实里、白色无边界） |

同一个页面里只允许一种机制。混两种，注意力就散了。

## 怎么用

1. **按机制选，不按风格选。** 用户要"科技感"，A 和 B 都能做到；先定机制再定样子。
2. **改写，不照抄。** 必须替换至少一个变量：材质 / 光温 / 异常类型 / 尺度方向（巨大 ↔ 极小）。并在输出里写明换了哪个。原样复述 = 换皮。
3. **同批多张要拉开差异。** 三张一起出时选"机制不同"的三个，别选"颜色不同"的三个。推荐最小差异集：`01 巨石（A）` + `02 赛博核心（B）` + `14 水墨（D）`。
4. **锚点不是越多越好。** 一个项目只用一个锚点贯穿全站；换锚点等于换品牌。

## 自造的三个条件

- 能用一个名词说清（说不清就不是锚点）
- 有明确的"停顿机制"，且只有一种
- 旁边能放下一个极小参照物

三个不满足，就回到这 18 个里挑一个。

## 轻档：6 个产品锚点

日常工具（笔记、记账、协作、社交、效率类）不需要巨石和深空。它们的主角就是**产品本身的一个实物**：一页笔记、一张卡、一个控件。保留 monument 的骨架（一个主角、一个光位、有质感的留白、唯一异常），放弃暗场和巨大尺度。

判断标准：停顿之后，观众 5 秒内要能说出"这是卖什么的"。产品锚点天然满足这一条，场景锚点要靠文案补救。

### P1 悬浮纸页
主体：一页写满真实内容的笔记，微微倾斜悬在空中
环境：浅灰空间，左上方天光形成的明暗梯度
材质：细纸纹 + 软接触阴影 + 纸边极细的厚度
光：左上 key，阴影落向右下
色：纸白 / 石墨 / 一点荧光笔色（只用在异常那一行）
异常：其中一行字从纸面浮起，带着自己的影子，连向另一条笔记
机制：B｜代码做法：CSS 3D transform + 两层阴影

### P2 放大的控件
主体：产品里最关键的那个控件（开关、滑块、按钮），放大到占半屏
环境：与控件同色系的纯净场，无边界
材质：做到能看见加工痕迹：倒角、磨砂、指纹
光：一盏 key 打出控件的高光与投影
色：中性灰 + 控件激活态的一个颜色
异常：用户能真的拨动这个巨大的控件
机制：A（日常小物放大）｜代码做法：CSS 渐变 + 内外阴影

### P3 剖面
主体：一张数据卡片被整齐切开，露出内部一层层的结构
环境：浅色无边界空间
材质：切面像亚克力或纸板，看得见层厚
光：侧光，把每层的边缘照亮
色：白 / 石墨 / 一个数据色
异常：界面有了厚度，内部是实物
机制：D｜代码做法：多层 div 错位 + 边缘高光

### P4 探照光
主体：一张真实的产品界面，几乎全暗
环境：界面本身就是环境
材质：屏幕
光：一束有方向的光扫过界面，只照亮最核心的那个功能
色：暗灰 / 一个光色
异常：光是从界面外打进来的
机制：C｜代码做法：mask-image 径向渐变 + 一次扫光动画

### P5 堆叠
主体：产品界面一层层叠成一摞，顶层翘起一角
环境：浅灰桌面感，不画桌子
材质：纸或磨砂玻璃，层与层之间有真实阴影
光：左上 key，翘起的角在下层投影
色：中性 + 一个强调色（只在翘起那一层）
异常：屏幕变成了可以掀开的纸
机制：B｜代码做法：CSS 3D transform + 逐层阴影

### P6 手边物
主体：产品界面旁放着一个真实物件（铅笔、回形针、杯子）
环境：浅色纯净场
材质：物件做到写实，界面保持平面
光：同一盏 key 同时照亮物件和界面
色：中性 + 物件自身的颜色
异常：比例不对：回形针和整个界面一样大
机制：A｜代码做法：SVG 物件 + 统一投影方向

产品锚点同样要遵守改写规则：至少替换一个变量，并在输出里写明换了哪个。
