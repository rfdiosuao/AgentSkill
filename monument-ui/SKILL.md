# Monument UI

## 法则

炸裂感 = 极简秩序 × 巨大尺度 × 超现实主体 × 真实材质 × 电影光影

不等于：霓虹 + 粒子 + 渐变 + 玻璃拟态 + 20 张卡片。

第一眼要让人产生"这是什么？"的停顿；第二眼他才看按钮和文字。没有这个停顿，就是穿了高级衣服的模板。

## 第 0 条：80% 测试（终极判据）

> **把 80% 的装饰元素删掉，这一屏必须依然炸。**

这是唯一一条全局面条，其余 18 条都为它服务。它同时是验收方式和设计方法：

- 设计时：先只放主体 + 主标题 + 一个按钮，这三样必须先成立。成立之后再往回收，而不是先堆满再删。
- 验收时：用 `?bare=1` 打开裸版（JS 里 `location.search` 带 `bare` 时给 body 加 `.bare`，`.bare` 隐藏所有装饰层、粒子、渐变、光晕），截两张图对比。
- 裸版不成立 → 问题在构图和主体，不在装饰。回去换锚点，不许靠加东西救。

**给不出裸版截图，就等于没做。**

## 何时用 / 何时不用

**用**：Hero、首发页、作品集、活动页、品牌开场、功能单页的展示区；给图像模型写场景提示词。

**不用**（但可借用）：数据看板、后台表格、设置页、需要 30 个以上操作项的密集界面。这类只借"一个主角 + 三层纵深 + 唯一记忆点"，元素上限与留白比例失效。

冲突时必须明说：**"这是操作界面，我用 monument 的层级，但不砍你的必要控件。"**

## 五条硬约束

1. **主角 = 1。** 多一个抢戏的主体，重排，不是缩小。
2. **可见 UI 元素 ≤ 30。** 主按钮 1 个，次按钮 ≤ 1 个，其余降为文字链接或收进菜单。
3. **纵深 ≥ 3 层**：前景 UI / 中景主体 / 远景环境，三层亮度曲线单调（通常远暗 → 中最亮 → 前景中间调）。
4. **颜色 ≤ 3 族**：主色 1 + 强调色 1（面积 ≤5%）+ 中性灰阶。黑白灰不算单独一色。
5. **记忆点 = 1 个异常点**：恰好一个现实世界不该存在的东西，落在非视觉重心处，且是唯一不合常理的元素。

## 工作流（七步）

1. **选锚点。** 从 `references/anchors.md` 的 18 个锚点里挑，或照它自造一个。必须能说出主角的名词和"停顿机制"（尺度压迫 / 物理不可能 / 不该被发现 / 介质错位）。说不出，就是还没准备好。
2. **一句话艺术指导（≤60 字）。** 主体 + 材质 + 光位 + 一个异常。
3. **先搭裸版。** 只放主体、主标题、一个按钮，截图。这一步不成立，后面全白做。
4. **分配重量。** 主角 40–65%；标题压一侧；留白 ≥30%；主体中线偏移 ≥8%。
5. **打光。** 三盏灯：key（120° 上侧方）/ rim（背后 ±160°，key 的 55–65%）/ ambient（≤15%）。禁止全屏 bloom、禁止到处发光。
6. **上材质。** 只让一个材质做到能看见使用痕迹，其余降到 70%。
7. **回收装饰。** 逐层加回，每加一层问一次：裸版少了它会不会更弱？不会就删。最后跑 `references/checklist.md` 给数字。

## 排版即构图

- 只有两档字号：巨大标题 `clamp(4rem, 9vw, 12rem)`，行高 0.9–0.95，字距 -0.03em；其余 11–13px。
- 副标字距 +0.12em 起，全大写或全小写挑一个。
- 正文最大宽度 ≤ 34em，一屏最多 2 段。
- 标题可以压到主体上（压进受光区或阴影区），它本身就是构图。

## 尺度对比

巨大主角旁必须有极小参照物：一个人、一个按钮、一行 11px 的字。比例 ≥ 40:1。**没有参照物，宏大感不成立**——观众缺一把尺子。

## 动效预算

- 入场 1 次，≤1.2s，`cubic-bezier(.16,1,.3,1)`。
- 常驻动效最多 1 个（呼吸 / 漂浮 / 光移，三选一）。
- 同屏同时运动 ≤ 3 个元素。

## 出图模式 vs 实现模式

- **出图模式**（给图像模型写提示词）：用 `references/anchors.md` 的锚点 + `references/negatives.md` 的英文禁止尾巴，每次都带尾巴。不写尾巴，AI 生成味立刻回来。
- **实现模式**（写代码）：不依赖外链图片；用真 3D 或 CSS/SVG 伪造，并老实交代是伪造。代码里的等价禁令见 `negatives.md` 的 B 节。

## 输出格式

1. 锚点（一个名词）+ 停顿机制（四种里选一种）
2. 一句话艺术指导（≤60 字）
3. 构图说明：主体位置、留白比例、三盏灯方位、异常点在哪
4. 裸版截图（或裸版代码开关）
5. 代码（给全，禁止 `// ...` 省略）
6. 自检表：19 条全填实际数字

## 明确拒绝的事

- **"再炸裂一点"** → 不加霓虹粒子。放大尺度、换更硬的材质、压暗环境、扩留白，然后重跑 80% 测试。
- **"多放几个卖点"** → 先问唯一主角是谁；其余降为一行小字或一个切换按钮。
- **"参考某大厂"** → 只提取秩序（网格、层级、光），不复制外观与配色。
