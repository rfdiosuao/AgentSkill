# 3D and live components

All in `src/components/lab/`. Built on three 0.186 + @react-three/fiber 9 + drei 10, and `motion` for 2D.
Render with `<Canvas flat>` (tone mapping washes out the cadet colors) and draw outlines with the inverted-hull
`Shell` from OrbitScene (drei `Outlines` breaks here).

## OrbitScene — the signature（头像星系）

Portable copy for projects outside heang-design: `../assets/orbit-scene/` (see its README). Props: `bodies`,
`avatar` (default `/avatar.jpg`), `className`.

The astronaut avatar planet with HEANG sites and projects orbiting on −18° orbits, an asteroid belt, drag to spin,
hover/click a body to see or open it.

```tsx
const OrbitScene = lazy(() => import("../../src/components/lab/OrbitScene").then((m) => ({ default: m.OrbitScene })));

<Suspense fallback={<OrbitLoader size={120} label="星系加载中" />}>
  <OrbitScene bodies={heangBodies()} />
</Suspense>
```

- `bodies: OrbitBody[]` — `{ name, code, href, color, kind?: "sphere" | "ring" | "gem" | "sat", tier?: "major" | "minor", pinLabel? }`.
  `heangBodies(except?)` in `src/lib/sites.ts` builds them from `SITES` (inner, major) and `PROJECTS` (outer, minor);
  pinned labels: HA-01 / 02 / 04 / 06 only, so the scene stays readable.
- Orbits: majors on `[2.4, 3.2, 4.0]`, minors on `[5.0, 5.65]`; camera `[0, 6.2, 16.6]`, fov 38.
- Heavy (Three.js chunk): always lazy-load it and keep the `OrbitLoader` fallback, which marks `data-heang-loading`
  so the splash waits for the scene. Put it in a `grid place-items-center` slot (avoids a canvas height feedback loop).

## GravityField — the living ground

The 22px dot grid on a canvas, bending around the pointer like a gravity well.

```tsx
{dim === "cadet" && <GravityField variant="calm" />}
```

- `calm` (public sites): soft glow and slight brightening follow the pointer.
- `lab` (showcases): dots are pushed and light up; a click sends a gravity wave.
- Draws only while something moves; static under reduced motion. Pairs with the pointer FX ring (they don't overlap:
  one is the ground, the other is the cursor).

## ArtifactScene — hero objects

`<ArtifactScene variant="rock" | "core" />`: a single slowly turning object used as a world backdrop (gate / core
worlds). Follows the pointer a little; freezes under reduced motion.

## OrbitLoader — inline loading

`<OrbitLoader size={88} label="加载中" />`: a planet travelling the tilted orbit. Use as any Suspense fallback; it
carries `data-heang-loading`, so a page splash waits for it.

## Smaller live pieces

`Reveal` (scroll reveal from a visible state), `CountTo` (number roll-up for stats), `Marquee` (ticker band),
`ScrambleText` (mono label decode), `Magnetic` / `TiltCard` (explicit wrappers; the global pointer FX already covers
`.h-btn` and `.lift`, so prefer the hook classes), `DimBackdrop` / `DimFlip` (world switching only).

## Using them outside heang-design

Copy the component file plus what it imports (`src/lib/hooks.ts` for `useMode` / `useThemeKey`, tokens.css for the
colors it reads at runtime via `--h-*`). They read colors from CSS variables, so they follow light/dark and worlds.
